# Отчёт - Задача 3: Фитнес-тренер

## Специализация

Агент - персональный фитнес-тренер. Помогает рассчитать норму калорий и БЖУ, составить программу тренировок, дать советы по питанию. На вопросы не по теме отвечает: "Команда неизвестна".

## Инструменты (skills)

**calculate_bju** - рассчитывает суточную норму калорий (TDEE) по формуле Миффлина-Сан Жеора и расписывает БЖУ. Принимает вес, рост, возраст, пол и уровень активности.

**get_workout_plan** - возвращает готовую программу тренировок по цели (похудение / набор массы / поддержание) и количеству дней в неделю (2-5).

**get_nutrition_tips** - даёт список базовых советов по питанию под конкретную цель.

## Системный промпт

Агент строго ограничен темой фитнеса и питания. При нерелевантных запросах отвечает фиксированной фразой "Команда неизвестна" - это прописано в system prompt.

## Сервис

REST API на FastAPI. Эндпоинт `POST /generate` принимает JSON с полем `message` и возвращает ответ агента.

## Пример запроса

```bash
curl -X POST http://localhost:8000/generate \
     -H "Content-Type: application/json" \
     -d '{"message": "Рассчитай КБЖУ: вес 70кг, рост 175см, 23 года, женщина, низкая активность"}'
```

## Стек

`langchain`, `langchain-groq`, `fastapi`, `uvicorn`, `python-dotenv`
